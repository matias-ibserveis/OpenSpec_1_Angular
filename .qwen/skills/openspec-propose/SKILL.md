# Plan de Trabajo: Mi Primer Hola Mundo en Angular 🚀

## Contexto del Proyecto 🧭
Vamos a construir una aplicación web estructurada en componentes utilizando la versión actual de Angular (Componentes Standalone). La interfaz se dividirá en una barra de navegación y un contenedor principal.

## Reglas de Arquitectura 🏗️
* Todo componente nuevo se guardará en la carpeta `src/app/components/`.
* Se usarán componentes Standalone (sin NgModules).
* El archivo raíz `app.component.html` organizará los componentes en orden estricto.

## Tareas del Proyecto 📝
- [ ] Tarea 1: Crear la estructura base del proyecto e inicializar el componente de navegación `navbar` en la carpeta `components`.
- [ ] Tarea 2: Crear el componente de contenido principal `content` en la misma carpeta.
- [ ] Tarea 3: Ensamblar ambos componentes en el archivo raíz (`app.component.ts` y `app.component.html`) para mostrar el resultado final.
